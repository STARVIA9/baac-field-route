📖 คู่มือการอัปโหลดข้อมูล
📥
Import ลูกค้า
ไฟล์: .csv, .json, .xlsx, .xls
คอลัมน์ที่ต้องมี:
cif — เลข CIF (ห้ามซ้ำ)
name — ชื่อ-นามสกุล
คอลัมน์เสริม:
nickname, phone, address, lat, lng, riskLevel, tags
โหมด: append (ข้ามซ้ำ) / upsert (อัพเดท) / replace (ลบทั้งหมดแล้วใส่ใหม่)
📍
อัพพิกัด GPS
ไฟล์: .csv, .xlsx, .xls
คอลัมน์ที่ต้องมี:
cif — เลข CIF (ใช้ match กับลูกค้าเดิม)
พิกัด — "lat lng" (เว้นวรรค) หรือ "lat, lng"
หรือแยก 2 คอลัมน์:
lat + lng (หรือ latitude/longitude, ละติจูด/ลองจิจูด)
ผลลัพธ์: ลูกค้าเดิม → อัพเดทพิกัด / CIF ใหม่ → สร้างใหม่
📊
อัปเดตหนี้
ไฟล์: .csv (Customer Indicator จาก ธ.ก.ส.)
คอลัมน์: ระบบอ่านอัตโนมัติจากไฟล์ TIS-620
ต้องมี: CIF + ข้อมูลหนี้ (ชั้นหนี้, ยอดคงเหลือ, วันครบกำหนด)
ผลลัพธ์: อัปเดตข้อมูลหนี้ 9 คอลัมน์ในระบบ
หมายเหตุ: 1 CIF มีได้หลายสัญญา ระบบจัดการให้อัตโนมัติ
📤
Export ข้อมูล
ส่งออกเป็น: CSV หรือ JSON
เลือก field ได้: cif, name, phone, address, lat, lng, riskLevel, tags ฯลฯ
กรองได้: เฉพาะที่มี GPS / ไม่มี GPS / ตามคำค้นหา
CIF ชื่อ-นามสกุล เบอร์โทร ตำบล/อำเภอ GPS ความเสี่ยง Tags อัพเดท จัดการ
